# file-drop

личное хранилище файлов и текстовых заметок для одного пользователя. flask, локальные файлы, готовый интерфейс с lucide. без внешних сервисов и базы данных.

## запуск

нужны linux и python 3.11 или новее.

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
chmod 600 .env
python -c 'import secrets; print(secrets.token_hex(32))'
python -c 'from getpass import getpass; from werkzeug.security import generate_password_hash; print(generate_password_hash(getpass("пароль: ")))'
```

впиши в `.env` логин `DROP_USER`, случайный `DROP_SECRET_KEY` и полученный `DROP_PASSWORD_HASH`. значения заключай в одинарные кавычки, особенно хеш с символами `$`. готового пароля нет. приложение не запустится без обязательных значений. `.env` автоматически не читается.

```sh
set -a
. ./.env
set +a
gunicorn --bind 127.0.0.1:8090 --workers 1 --threads 4 'app:create_app()'
```

`DROP_DATA_DIR` по умолчанию `data` относительно рабочего каталога. используй отдельный закрытый каталог с правами 700. не клади его в static и не отдавай напрямую через веб-сервер. новые файлы имеют права 600. каталог и его родители не должны быть симлинками.

`DROP_MAX_MB` ограничивает весь запрос загрузки, включая multipart, по умолчанию 100 миб. поля формы ограничены 1 миб. общего лимита диска нет, настрой квоту и резервные копии отдельно.

cookie по умолчанию только для https. для локальной проверки через http выставь `DROP_COOKIE_SECURE=0`, для публичного сервиса оставь `1`. перед gunicorn нужен https reverse proxy с ограничением частоты запросов на `/login` и лимитом тела запроса. заголовкам forwarded приложение не доверяет. не запускай публично через flask debug.

## поведение

загрузка не перезаписывает существующие файлы. дубликаты получают суффикс перед расширением. скачивание всегда вложением. симлинки и обход каталогов отклоняются. csrf проверяется для всех изменяющих запросов, включая вход, выход и создание ссылки.

ссылки `/dl/...` бессрочные и многоразовые. любой обладатель ссылки может скачать файл без входа. удаление файла через интерфейс удаляет ссылки. не публикуй ссылки на чувствительные данные. не меняй файлы и ключи вручную в работающем хранилище.

«запомнить меня» сохраняет подписанную cookie на 30 дней. выход удаляет cookie в текущем браузере. для отзыва всех выданных сессий смени `DROP_SECRET_KEY`; украденная копия cookie иначе действует до истечения срока.

## проверка

```sh
python -m unittest discover -s tests -v
node --check static/files.js
```

тесты используют flask test_client и временные каталоги, реальные данные не нужны.
